## NekoType

> Android 系统级消息文本自定义工具 —— 悬浮按钮一键为输入框内容应用自定义规则（前缀/后缀/随机尾缀/文本替换）并自动发送

NekoType 是一款运行在 Android 上的系统级消息处理工具，核心目标只有一个：**让用户以最小的操作成本，把聊天输入框里的文本按照自定义规则改写后一键发送**。你正常打字，点击屏幕边缘常驻的悬浮按钮，消息会自动完成「文本替换 → 前缀 → 后缀 → 随机尾缀 → 自动发送」的完整流程。例如添加一条"前缀"规则值为 `~`、一条"后缀"规则值为 `喵`，输入 `好的`，发出的就是 `~好的喵`；添加一条"随机后缀"规则，则每条消息还会按触发概率追加不同的随机尾缀，让内容不再千篇一律。

它不是输入法皮肤或聊天美化插件，而是一套完整的**系统能力集成方案**：通过 Android 无障碍服务感知并读写当前输入框文本，通过系统悬浮窗提供全局触达入口，通过 Shizuku / Root 获得系统级命令执行能力（如直接写入电池优化白名单，保证后台常驻）。项目内置三种运行模式——**基础模式 / Shizuku 模式 / Root 模式**——按需切换，核心功能最低仅需「悬浮窗 + 无障碍」两项权限即可跑通，绝大多数用户开箱即用，无需 Root。

**最重要的是：NekoType 完全离线运行。应用本体不申请任何网络权限，没有联网能力，更没有服务器——你的每一句话、每一条规则都只存在于你自己的手机里。我们对您的数据并不感兴趣，因为根本接触不到。**

## ✨ 核心特性

### 规则系统（自由组合，多条并存）

规则页采用**规则列表**模型，点「添加规则」即可按类型创建，规则按顺序叠加生效：

| 规则类型 | 配置项 | 示例  |
| --- | --- | --- |
| **前缀** | 内容  | 内容 `~` → 输入 `好的` 发出 `~好的` |
| **后缀** | 内容  | 内容 `喵` → 输入 `好的` 发出 `好的喵` |
| **随机前缀** | 内容池（`\\|` 分隔）+ **触发概率 %（1-100）** | 随机池 · 概率 50% |
| **随机后缀** | 内容池（`\\|` 分隔）+ **触发概率 %（1-100）** | 池 `qwq\\|awa\\|nya~` · 概率 50% |
| **替换文本** | 检测的字 + 替换的文字 | `的` → `の`，输入 `好的` 发出 `好の` |

* 每条规则可随时**开关 / 删除**，随机规则按各自概率独立触发（不再"每次必发"）
* 内置**多套规则预设**，可一键选择 / 删除，每套预设拥有独立规则列表，适配不同使用场景
* 附加全局样式：字符间加空格、转为大写
* 规则列表实时预览：在「效果预览」里输入任意文本，立即看到当前全部规则的叠加结果，改规则、看效果一目了然

### 强制篡改键盘

**不换键盘、不装输入法，原生键盘打字时内容自动被按规则篡改**

* 开启后，在任意输入框用系统原生键盘输入，停顿片刻文本会自动按你的规则变换，**无需点击悬浮按钮**
* 采用**增量原文算法**：记录你的真实输入，只把新增部分并入原文后重新变换，**连续打字时后缀/前缀永远不会重复叠加**（不会出现"喵喵喵"）
* 写回后**自动把光标移到末尾**，继续输入不打断；内置 600ms 回显窗口，彻底防止循环改写
* **发送兜底**：你手动点击发送按钮的瞬间，会先确保文本已篡改再发出去，杜绝"来不及改就发出去了"
* 启用前弹出**免责声明**，确认后生效；随时关闭开关即可恢复原样

### 静默修改

* 当部分应用（如微信）拒绝无障碍改写文本时，自动改用 **Shizuku / Root 直接注入**，全程**无弹窗、无剪贴板提示**，改完即走
* 中文文本自动回退无障碍通道，两种方式互为兜底，尽可能保证每一次改写都成功且安静

### 悬浮按钮

* **永久常驻**屏幕边缘（默认右侧居中），图标可替换为任意图片，点击带水波纹反馈
* 按住拖动自由摆放、自动**边缘吸附**、位置持久记忆
* 点击 = 变换 + 发送（可关闭自动发送，仅改写文本）；常驻通知栏，一键停止
* 可选**柔光玻璃效果**、**空闲收起成小圆点**（5 秒无操作自动缩起，点击展开）、自定义大小与透明度

### 智能发送

三级兜底策略，兼容主流聊天应用：

1. 在无障碍节点树中查找「发送」按钮（文本 / 控件 ID / contentDescription 启发式匹配）→ `ACTION_CLICK`
2. 回退 IME 发送动作（`ACTION_IME_ACTION_SEND`）
3. 再失败使用全局手势点击发送键屏幕坐标

### 日志功能显示

内置**运行日志查看器**（右上角设置 → 日志）：

* 7 级日志体系：信息 / 成功 / 警告 / 错误 / 导航 / 调整 / 规则，每条操作都有迹可循
* **系统日志直读**：直接抓取系统 `logcat`，变换失败、发送被拦截等疑难问题一眼定位
* **轻汉化**：系统日志标签自动转成中文，非开发者也能看懂
* 日志字体可缩放，支持复制导出，排查问题、提交反馈都方便

### 外观与个性化

* **三套主题**：深色 / 浅色 / 跟随系统，随时切换
* **自定义背景**：选择任意图片作为应用背景（仅保存在本地），自适应缩放不变形
* 悬浮按钮大小、透明度自由调节，实时生效

### 数据管理

* **一键导出 / 导入全部配置**（规则 + 行为 + 外观），文本格式可读可编辑，换机、分享、备份都方便；兼容旧版 JSON 配置
* **每日统计**：今日变换次数 + 最近 7 天趋势 + 累计次数，一目了然

### 权限与系统能力

| 能力  | 用途  | 获取方式 |
| --- | --- | --- |
| 悬浮窗 | 显示悬浮按钮 | 系统设置授权 |
| 无障碍 | 读写输入框 / 触发发送 | 系统设置开启 |
| 关闭电池优化 | 后台常驻不被杀 | 系统弹窗 **或** Shizuku/Root 直写白名单 |
| Shizuku | 系统级 shell 命令（免 Root） | 安装 Shizuku + 无线调试/ADB 授权 |
| 设备管理员 | 额外系统能力（可选） | 系统设置激活 |
| Root | 最高权限命令执行 | Magisk / KernelSU / APatch |

内置**五步权限引导向导**：无障碍 → 设备管理员 → 关闭省电优化 → 显示在应用上层 → Shizuku 授权（或进入基础模式），逐项点亮状态，全部就绪后悬浮按钮永久常驻。另有**快捷设置磁贴**（下拉面板一键开关服务）与**开机自启**选项。

## 🔧 三种运行模式

| 模式  | 权限依赖 | 系统命令（如免电白名单） |
| --- | --- | --- |
| **基础模式**（默认） | 仅悬浮窗 + 无障碍 | 不执行，核心变换/发送功能完整可用 |
| **Shizuku 模式** | 悬浮窗 + 无障碍 + Shizuku 授权 | 经 Shizuku UserService（shell 权限）执行 |
| **Root 模式** | 悬浮窗 + 无障碍 + Root | 经 `su` 执行（Magisk / KernelSU / APatch） |

* **基础模式**：零系统命令，适合绝大多数用户，开箱即用
* **Shizuku 模式**：免 Root 获得系统级能力，适合想要"静默修改"等增强功能的用户
* **Root 模式**：最高权限，适合已 Root 的发烧友

## 🛠 技术原理

| 能力  | 实现方式 |
| --- | --- |
| 读取 / 改写其他 App 的 EditText | `AccessibilityNodeInfo.ACTION_SET_TEXT`（官方无障碍 API，带验证重试） |
| 触发发送 | 三级策略：发送按钮点击 → IME 动作 → 全局手势 |
| 悬浮按钮 | `TYPE_APPLICATION_OVERLAY` + `FLAG_ALT_FOCUSABLE_IM`，拖放 + 位置持久化 + 边缘吸附 |
| 系统命令执行 | Root（`su`）或 Shizuku UserService（**Messenger 方案**，Shizuku 13 已移除 `newProcess`） |
| 规则存储 | 本地 SharedPreferences + JSON 序列化，多套预设互不干扰 |
| 静默注入 | Shizuku/Root 执行 `input text` 直写聚焦输入框，绕过应用对无障碍的限制 |
| 防叠加篡改 | 增量原文算法：记录用户真实输入 + 上次写回内容，只合并新增部分后重新变换 |

全部基于 Android 官方公开 API 实现，**无私有 API、无 Xposed、无 Hook、无任何注入框架**。

## 💾 纯本地与隐私承诺

**一句话：NekoType 不联网，你的数据只在你的手机上。**

* **纯本地化离线运行**：应用不申请 `INTERNET` 网络权限，**没有任何联网能力**——没有服务器、没有云端、没有遥测。断网、开飞行模式，所有功能照常运行
* **我们对您的数据并不感兴趣**：因为技术上看不到——所有文本读取、规则变换、发送触发全部在设备本地内存中完成，处理完即丢弃，不留存、不上传
* **零广告、零统计、零追踪**：不含任何广告 SDK、统计 SDK、推送 SDK。你看到的就是全部代码
* **本地存储**：仅规则配置、外观设置、变换次数统计等保存在本地 `SharedPreferences`，随卸载一并清除
* **权限最小化**：无障碍仅用于读取/改写当前输入框并触发发送，不读取密码框（`isPassword = true` 的节点无障碍本身也无法获取文本）；悬浮窗仅用于显示按钮；所有权限都可随时在系统设置中撤销
* **可审计**：项目完全开源，任何一条权限、任何一行代码你都可以查看

## 🚀 使用方式

1. 安装后打开 App → 启动服务 → 按权限引导顺序授予权限（无障碍 + 悬浮窗为必需，其余可选）。
2. 悬浮按钮常驻屏幕边缘；在任意聊天 App 输入文字后点击按钮，文本自动按规则变换并发送。
3. 在「规则」页点「添加规则」创建前缀/后缀/随机/替换规则，随时开关与删除；可切换多套预设。
4. 想全自动？在「行为与样式」开启**强制篡改键盘**（原生键盘打字即自动篡改）与**静默修改**（Shizuku 直写无弹窗）。
5. 右上角设置：更换运行模式、查看运行日志、导出/导入配置、查看详细信息 / 版本号、意见反馈、赞助支持、隐私政策。

## ❓ 常见问题（FAQ）

**需要 Root 吗？**不需要。基础模式仅需悬浮窗 + 无障碍；想要"静默修改"等增强功能，装个 Shizuku（免 Root）即可。

**微信 / QQ 能用吗？**能。智能发送针对微信等主流应用做了专门的发送按钮识别与兜底策略，兼容性优先。

**会读取我的聊天记录吗？**不会。NekoType 只读取**当前聚焦输入框**里的文本，不扫描、不记录、不存储聊天内容。

**强制篡改键盘会把后缀叠加成"喵喵喵"吗？**不会。增量原文算法保证每次只在你的真实输入上重新变换一次，连续打字后缀也只出现一次。

**开启强制篡改键盘有风险吗？**请先阅读并确认免责声明：仅限本人设备、合法合规的个人用途，禁止用于骚扰、诈骗、冒充他人等非法用途，后果自负。

**耗电吗？**无障碍事件监听为系统级轻量回调，无轮询、无常驻网络，耗电可忽略。

**如何彻底停用？**App 内关闭「启动服务」，并在系统设置中撤销无障碍 / 悬浮窗权限，卸载即清除全部本地数据。

## ⚙️ 构建

### Windows（一键脚本）

    # 前置：JDK 17+、Android SDK（ANDROID_HOME 或默认 %LOCALAPPDATA%\Android\Sdk）
    powershell -ExecutionPolicy Bypass -File sign_and_build.ps1
    # 产物: app\build\outputs\apk\release\app-release.apk （已签名）

### Linux / macOS

    chmod +x sign_and_build.sh
    ./sign_and_build.sh

### 手动构建

    git clone https://github.com/<you>/NekoType.git
    cd NekoType
    ./gradlew assembleRelease

要求：JDK 17+，Android SDK Platform 34 + Build-Tools 34.0.0，Gradle 8.7（仓库已内置 wrapper）。
